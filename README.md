# Typing Speed Test 

A web-based typing speed test application built using HTML, CSS, and JavaScript.

## Features

- Calculate typing speed (WPM)
- Track typing accuracy
- Real-time timer
- Random typing passages
- Display typing results
- User-friendly interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## How It Works

The application measures how fast and accurately a user can type a given text. It calculates typing performance based on speed, time, and accuracy.
